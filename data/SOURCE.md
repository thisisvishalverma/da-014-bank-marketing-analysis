# Dataset source and attribution

This project bundles **Bank Marketing (`bank-additional-full.csv`)** from the UCI Machine Learning Repository.

- Dataset page: <https://archive.ics.uci.edu/dataset/222/bank+marketing>
- DOI: `10.24432/C5K306`
- License listed by UCI: CC BY 4.0
- File used: `bank-additional-full.csv` (41,188 records; 20 predictor columns plus the target `y`)
- Official download archive: <https://archive.ics.uci.edu/static/public/222/bank+marketing.zip>

The target `y` indicates whether the client subscribed to a term deposit (`yes`/`no`). This project preserves the source records and includes a cleaned runtime view generated by `analysis.py`. Literal `unknown` categories are retained as `Unknown`; `?` values are treated as missing. Only rows with an invalid target would be excluded from the response-rate denominator.

UCI asks users of the dataset to cite:

> Moro, S., Rita, P., & Cortez, P. (2014). Bank Marketing. UCI Machine Learning Repository. <https://doi.org/10.24432/C5K306>
